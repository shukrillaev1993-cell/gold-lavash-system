# Android — сборка и публикация

## Что нужно установить (один раз)
1. [Android Studio](https://developer.android.com/studio) — бесплатно.
2. При первом запуске Android Studio сам предложит скачать Android SDK —
   соглашайтесь со всем по умолчанию.

## Сборка и запуск
1. Откройте Android Studio → **Open** → выберите папку `mobile/android`
   (именно эту, не `mobile`).
2. Дождитесь автоматической синхронизации Gradle (внизу будет прогресс-бар,
   первый раз может занять несколько минут — скачиваются зависимости).
3. Подключите телефон по USB (включите на телефоне «Отладка по USB» —
   Настройки → О телефоне → 7 раз нажать «Номер сборки» → появится «Для
   разработчиков» → включить USB-debugging), либо запустите эмулятор
   (Android Studio → Device Manager → Create Device).
4. Нажмите зелёную кнопку ▶ **Run** — приложение установится и откроется.

## Проверка
- Приложение должно открыть тот же мобильный интерфейс, что и в браузере
  по адресу `.../exec?mobile=1`.
- Зайдите в «Основные средства» → любую карточку с кнопкой «📷 Фото» — должно
  запросить разрешение на камеру и открыть камеру/галерею на выбор.
- Кнопка «Назад» на телефоне должна листать историю внутри приложения, а не
  сразу закрывать его.
- Если нет интернета — должен показаться экран «Нет подключения» с кнопкой
  «Повторить».

## Публикация в Google Play
1. Зарегистрируйте аккаунт разработчика: https://play.google.com/console/
   (разовый взнос $25).
2. В Android Studio: **Build → Generate Signed Bundle / APK** → **Android App
   Bundle** → создайте новый ключ подписи (keystore) — **сохраните этот файл
   и пароли в надёжном месте**, без него нельзя будет выпускать обновления
   этого же приложения в будущем.
3. Загрузите получившийся `.aab` в Play Console → создайте приложение →
   заполните карточку (название, описание, скриншоты, политику
   конфиденциальности — Google это требует даже для внутренних приложений)
   → отправьте на проверку.
4. Для отправки только своим сотрудникам (без публичной публикации) в Play
   Console есть режим **закрытого тестирования** — это быстрее и не требует
   полной проверки магазина.

## Известные ограничения текущей версии
- Иконка приложения — простая заглушка (тёмный квадрат + золотой круг,
  `res/drawable/ic_launcher.xml`). Замените на реальный логотип, когда он
  будет — просто перекиньте PNG/векторный файл в `res/mipmap-*` или
  `res/drawable` под тем же именем `ic_launcher`.
- Не настроены push-уведомления — сейчас не было запроса на них; если
  понадобится оповещать сотрудников (например, о новой инвентаризации),
  это отдельная задача (Firebase Cloud Messaging).
