# iOS — сборка и публикация

Собрать и запустить iOS-приложение можно **только на Mac** с установленным
Xcode (это ограничение Apple, не моё — на Windows/Linux Xcode не существует).
Если своего Mac нет — есть облачные сервисы сборки (Codemagic, Bitrise,
GitHub Actions с macOS runner), но это отдельная настройка вне этой сессии.

## Что нужно
1. Mac + [Xcode](https://apps.apple.com/app/xcode/id497799835) (бесплатно из
   App Store).
2. Apple ID (обычный, бесплатный) — для запуска на своём телефоне через USB.
3. Для публикации в App Store — платный **Apple Developer Program**,
   $99/год: https://developer.apple.com/programs/

## Шаг 1 — создать проект в Xcode
1. Xcode → **File → New → Project** → **iOS → App**.
2. Product Name: `GoldLavash`. Interface: **Storyboard**. Language: **Swift**.
   Остальное — по умолчанию.
3. Сохраните проект куда угодно (например, рядом с этой папкой, но это не
   обязательно — проекты не связаны файлово, только логически).

## Шаг 2 — подставить готовый код
1. В созданном проекте найдите файл `ViewController.swift` (уже создан
   Xcode-шаблоном) и **полностью замените его содержимое** на файл
   [ViewController.swift](GoldLavash/ViewController.swift) из этой папки —
   просто скопируйте текст.
2. Больше ничего менять не нужно — `AppDelegate.swift`, `SceneDelegate.swift`
   и `Main.storyboard`, которые создал Xcode, остаются как есть (Storyboard
   сам создаёт этот `ViewController` при запуске).

## Шаг 3 — разрешения на камеру (обязательно, иначе камера не откроется)
Начиная с iOS 14.5 `WKWebView` сам показывает системный выбор «Камера /
Библиотека фото» для полей загрузки файла на страницах — отдельный код для
этого не нужен (в отличие от Android). Но iOS не даст открыть камеру без
явного описания причины в `Info.plist`:

1. В навигаторе Xcode откройте `Info.plist` (или `Info` вкладку настроек
   таргета в новых версиях Xcode — там же можно добавить через `+`).
2. Добавьте два ключа (как **Property List**, тип String):
   - `Privacy - Camera Usage Description` (`NSCameraUsageDescription`) →
     `Нужен доступ к камере для фотографирования основных средств`
   - `Privacy - Photo Library Usage Description`
     (`NSPhotoLibraryUsageDescription`) →
     `Нужен доступ к галерее для загрузки фото основных средств`

Если этого не сделать — приложение аварийно закроется при попытке открыть
камеру (это стандартное требование Apple, не баг).

## Шаг 4 — запуск и проверка
1. Подключите iPhone по кабелю, выберите его в списке устройств вверху
   Xcode, нажмите ▶ **Run**. Первый раз потребуется на телефоне: Настройки →
   Основные → VPN и управление устройством → довериться разработчику.
2. Проверьте: открывается мобильный интерфейс системы, работает переход по
   разделам, в «Основные средства» кнопка «📷 Фото» открывает выбор
   камеры/галереи и после съёмки фото загружается.

## Публикация в App Store
1. Оформите Apple Developer Program ($99/год).
2. В Xcode: **Product → Archive** → **Distribute App** → **App Store
   Connect** → следовать мастеру (потребуется завести карточку приложения на
   https://appstoreconnect.apple.com/, скриншоты, политика
   конфиденциальности — как и у Google, обязательна даже для внутреннего
   приложения).
3. Для раздачи только своим сотрудникам без публичного магазина — есть
   **TestFlight** (до 10 000 тестировщиков по ссылке, без полной проверки
   Apple) — это быстрее для старта.

## Если адрес системы изменится
В `ViewController.swift` — константа `appURLString` в начале файла.
