# iOS — установка на свой iPhone без Mac

Xcode существует только под macOS — собрать проект локально на Windows нельзя,
это ограничение Apple. Но поставить готовое приложение на свой iPhone можно
и без своего Mac: сборка делается в облаке (на настоящем Mac у сервиса
Codemagic), а установка на телефон — через программу для Windows.

Проект (`GoldLavash.xcodeproj` в этой папке) я собрал вручную — без Xcode нет
возможности открыть и проверить его до первой сборки в облаке. Структуру и
все ссылки между файлами я проверил насколько это возможно без самого Xcode.
Если сборка в Codemagic выдаст ошибку — пришлите мне текст ошибки из лога
сборки, я поправлю проект.

## Шаг 1 — выложить код на GitHub

1. Зарегистрируйтесь на https://github.com (бесплатно), если ещё нет аккаунта.
2. Создайте новый **приватный** репозиторий (например `gold-lavash-system`) —
   пустой, без README/лицензии.
3. У вас уже готов локальный git-репозиторий в этой папке
   (`c:\Users\User\Documents\AgenClaude`). Свяжите его с GitHub и отправьте код
   (замените `<ваш-логин>` и `<название-репозитория>` на свои):
   ```
   git remote add origin https://github.com/<ваш-логин>/<название-репозитория>.git
   git branch -M main
   git push -u origin main
   ```
   GitHub попросит войти — используйте Personal Access Token вместо пароля
   (GitHub → Settings → Developer settings → Personal access tokens →
   Generate new token, права: `repo`).

## Шаг 2 — подключить Codemagic

1. Зарегистрируйтесь на https://codemagic.io — можно войти через тот же
   GitHub-аккаунт (кнопка «Sign up with GitHub»), это самое простое.
2. **Add application** → выберите ваш репозиторий `gold-lavash-system`.
3. Codemagic сам увидит файл `codemagic.yaml` в корне репозитория (я его уже
   подготовил) — выберите workflow **«GoldLavash iOS — unsigned .ipa»**.
4. Нажмите **Start new build**. Первая сборка занимает несколько минут —
   Codemagic сам берёт настоящий облачный Mac, собирает приложение и
   упаковывает его в `.ipa` **без цифровой подписи** — это специально: подпись
   сделает бесплатным Apple ID уже сама программа для установки на шаге 3, ни
   платный Apple Developer аккаунт, ни настройка сертификатов в Codemagic не
   нужны.
5. Когда сборка закончится — на вкладке **Artifacts** появится файл
   `GoldLavash-unsigned.ipa`, скачайте его на компьютер.

Если сборка упадёт с ошибкой — откройте лог сборки, скопируйте текст ошибки и
пришлите мне, я поправлю `mobile/ios/GoldLavash.xcodeproj` или `codemagic.yaml`.

## Шаг 3 — установить .ipa на iPhone через Windows

1. Скачайте **Sideloadly**: https://sideloadly.io/ (есть версия для Windows),
   установите.
2. Подключите iPhone к компьютеру по кабелю (на телефоне подтвердите
   «Доверять этому компьютеру»).
3. Установите на компьютер **iTunes** (или Apple Mobile Device Support) — это
   нужно самому Sideloadly, чтобы видеть телефон; Sideloadly подскажет, если
   его не хватает.
4. В Sideloadly: перетащите скачанный `GoldLavash-unsigned.ipa` в окно
   программы, укажите свой Apple ID (обычный бесплатный, регистрируется на
   appleid.apple.com) и пароль — Sideloadly сам подпишет приложение этим
   Apple ID и установит на телефон.
5. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   найдите свой Apple ID в разделе «Разработчик» → **Доверять** (без этого
   iOS не даст открыть только что установленное приложение).

**Ограничение бесплатного Apple ID (правило Apple, не моё):** такое
приложение перестаёт открываться через **7 дней** и требует переустановки —
просто повторите шаг 4. Если это неудобно, поставьте **AltStore**
(https://altstore.io/) вместо Sideloadly — он умеет переустанавливать
(«refresh») приложение автоматически по Wi-Fi раз в 7 дней, без кабеля,
пока телефон и компьютер в одной сети.

## Проверка после установки
- Приложение должно открыть тот же мобильный интерфейс, что и в браузере
  по адресу `.../exec?mobile=1`.
- В «Основные средства» → карточка с кнопкой «📷 Фото» — должно запросить
  разрешение на камеру и открыть системный выбор «Камера / Библиотека фото».

## Если нужна публикация в App Store (позже, не сейчас)
Это отдельная история — требует платного Apple Developer Program ($99/год) и
проверки приложения Apple (нужны скриншоты, политика конфиденциальности и
т.д.). Codemagic также умеет это делать в облаке без своего Mac (workflow с
подписанным `.ipa` и загрузкой в App Store Connect через API-ключ) — если
дойдёте до этого этапа, напишите, настрою отдельный workflow.
