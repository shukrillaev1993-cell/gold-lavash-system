    Голосовой режим
    
      
      

      
    Telegram-бот
    
      
      
      
      
      
      
      
    
        1) Создайте бота через @BotFather в Telegram, вставьте токен сюда и сохраните.
        2) Напишите боту любое сообщение — он пришлёт ваш chat ID, впишите его сюда и сохраните снова.
        3) Запустите бота командой npm run bot в папке jarvis.
      
    

      
      
      
      
      
    
        Пока ПК включён и бот запущен — отвечает он сам (голос, команды). Когда бот выключен —
        отвечает облачный резерв на Apps Script (только текст, без команд и голоса).
        Данные продаж Gold Lavash тоже читаются через этот адрес (list_sales_sheets/read_sales_sheet) —
        отдельная настройка Google Sheets не нужна.
